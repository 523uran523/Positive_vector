# Структура приложения — CRM «Позитив Вектор»

## Разделы приложения (главное меню)

Для **Администратора** (8 разделов):
| Раздел | Идентификатор | Описание |
|--------|--------------|----------|
| Работа | `calendar` | Календарь заказов, выездов и смен; создание заказов, учёт времени работы |
| Финансы | `finance` | Обзор KPI, экономика заказов, платежи клиентов, расходы, отчёты по работе |
| Склад | `warehouse` | Материалы, инструменты, приход/списание/возврат, журнал операций |
| Чат | `chat` | Общий чат, ответы на сообщения, вложения (фото/видео/документы), push-уведомления |
| Документы | `documents` | Акты и чертежи, загрузка/скачивание/удаление файлов |
| Клиенты | `clients` | Компании и контакты, история заказов, долги |
| Сотрудники | `employees` | Учётные записи, ставки, увольнение/восстановление, зарплаты |
| Настройки | `settings` | Профиль, пароль, компания, Яндекс Диск, push, выход |

Для **Сотрудника** (4 раздела):
| Раздел | Идентификатор | Описание |
|--------|--------------|----------|
| Работа | `calendar` | Календарь, свои заказы и выезды |
| Чат | `chat` | Чат и вложения |
| Моя зарплата | `salary` | Начисления, выплаты, остаток, история смен |
| Настройки | `settings` | Профиль, пароль, тема, push, выход |

## Структура исходного кода

```
src/
  App.tsx              — точка входа React, роутирование разделов, deep links (?order=, ?task=, ?chat=)
  components/
    AppShell.tsx       — навигационное меню (боковое на ПК, нижняя панель на телефоне)
    AuthScreen.tsx     — экран входа и первичной настройки
    DismissedScreen.tsx — экран уволенного сотрудника
    OfflineIndicator.tsx — индикатор офлайна и очередь операций
    PWAInstallButton.tsx — кнопка установки PWA
    SectionHeader.tsx  — заголовок раздела
    ThemeContext.tsx   — светлая/тёмная тема
  lib/
    api.ts             — helper-функции форматирования (formatRub, formatDateRu и др.)
    apiTransport.ts    — apiRequest, CSRF-токен, офлайн-очередь, кэш
    offlineDb.ts       — IndexedDB: офлайн-сессия, очередь мутаций
    push.ts            — enablePushNotifications (клиентская часть push)
    upload.ts          — uploadWithRetry (XHR, 3 попытки, прогресс, Wake Lock)
  views/
    CalendarView.tsx   — календарь заказов, выездов, смен; быстрые задачи
    ChatView.tsx       — чат, ответы, вложения, полноэкранный просмотрщик
    ClientsView.tsx    — клиенты, компании, контакты
    DocumentsView.tsx  — документы (акты/чертежи), загрузка, удаление
    EmployeeSalaryView.tsx — зарплата сотрудника: начисления, выплаты, отчёты
    EmployeesView.tsx  — учётные записи сотрудников (только админ)
    FinanceView.tsx    — финансы: обзор, экономика заказов (инлайн-редактирование), платежи, расходы, отчёты по работе
    OrderModals.tsx    — модалки заказов: создание, детали, оплата, файлы, смены, время работы
    QuickTasks.tsx     — быстрые задачи
    ReportsView.tsx    — отчёты по выездам и сменам
    SettingsView.tsx   — настройки: профиль, компания, Яндекс Диск, push, сотрудники (админ)
    WarehouseView.tsx  — склад: материалы, инструменты, операции
    WorkView.tsx       — заглушка раздела «Работа» с подвкладками

server/
  app.ts               — Express app, монтирование роутов
  server.ts            — точка входа, таймауты Node для загрузок
  db.ts                — инициализация SQLite, WAL, транзакции
  middleware.ts        — аутентификация, сессии, CSRF, cookie
  security.ts          — RBAC, права, уведомления (notifyUser → notifyPush)
  config.ts            — переменные окружения
  routes/
    auth.ts            — авторизация, сессии, Setup
    chat.ts            — чат, сообщения, вложения, push подписки (legacy)
    clients.ts         — клиенты, компании, контакты
    documents.ts       — документы (акты/чертежи), загрузка, скачивание, удаление
    export.ts          — XLSX-экспорт
    finance.ts         — финансы: обзор, платежи, расходы, корректировка себестоимости
    orders.ts          — заказы, выезды, материалы, отчёты, время работы
    push.ts            — push-уведомления: ключ, подписка, удаление
    reports.ts         — отчёты по выездам и сменам с фильтрами
    salaries.ts        — зарплаты: сводка, журнал, месячные отчёты
    settings.ts        — настройки компании, Яндекс Диск
    shifts.ts          — смены в цеху
    users.ts           — сотрудники, права, директория
    warehouse.ts       — склад: материалы, инструменты, операции
    yandexIntegration.ts — Яндекс Диск (резервные копии)
  services/
    push.ts            — sendPushToUser, sendPushToRoom, notifyPush
    backup.ts          — резервное копирование БД и файлов
    yandexOAuth.ts     — OAuth для Яндекс Диска
  migrations/
    001_init.sql … 019_visit_work_times.sql — версиями БД
  scripts/
    migrate.ts, create-admin.ts, seed:demo.ts, resetData.ts

public/
  chat-push.js         — service worker для push-уведомлений (tag, url, notificationclick)
  pwa-*.png            — икононки PWA
  sw.js                — сервис-воркер (auto-generated VitePWA)

tests/
  *.test.ts            — автотесты бизнес-логики (41 тест)

docs/
  TECHNICAL.md         — техническая документация (этот файл)
  STRUCTURE.md         — структура приложения (этот файл)
  CHANGES_2026-11-22.md — список изменений (что сделано)
  IMPROVEMENT_PLAN_2026-11-21.md — план оставшейся работы
  USER_GUIDE.md        — руководство пользователя
```

## Модель данных (основные таблицы)

| Таблица | Описание |
|---------|----------|
| `users` | Пользователи (админы, сотрудники), роли, права, пароли |
| `sessions` | Активные сессии авторизации |
| `orders` | Заказы (цена, статус, адрес, клиент, даты) |
| `order_visits` | Выезды по заказу (статус, дата, время) |
| `visit_reports` | Отчёты по выездам (работа, примечания) |
| `workshop_shifts` | Смены в цеху (время, ставка, выполнено) |
| `visit_work_times` | Индивидуальное время начала/конца дня выезда |
| `clients`, `contacts` | Компании и контакты |
| `materials`, `tools` | Склад: материалы и инструменты |
| `warehouse_ops` | Операции со складом (приход/списание/возврат) |
| `client_payments` | Платежи клиентов |
| `expenses` | Расходы компании |
| `salary_accruals`, `salary_payouts` | Начисления и выплаты зарплат |
| `audit_log` | Аудит действий |
| `push_subscriptions` | Подписки на push-уведомления |
| `documents` (бывш. `accounting_documents`) | Загруженные документы (акты/чертежи) |
| `attachments`, `chat_files` | Вложения к заказам и чату |
