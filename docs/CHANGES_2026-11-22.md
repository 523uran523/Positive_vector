- **Отчёты по работе** — компонент ReportsView (отчёты по выездам и сменам)
- **Платежи клиентов**
- **Расходы**

Вкладка «Экономика заказов» удалена как отдельная — её содержимое объединено со вкладкой «Обзор».

### Кнопка «Отчёты по работе»
Размещена внутри вкладки «Обзор» сразу после заголовка. При клике открывает компонент `ReportsView` с отчётами по выездам (`visit_reports`) и сменам (`workshop_shifts`).

### Инлайн-редактирование таблицы «Экономика заказов»
Поля таблицы теперьeditable прямо из строки:
- **Цена** — `PATCH /api/orders/:id` с `priceKopecks`
- **Оплачено** — `POST /api/finance/payments` (новая оплата к заказу)
- **Долг** — пересчитывается как `цена − оплачено`, редактирование меняет цену заказа
- **Материалы** — `POST /api/finance/orders/:orderId/cost-override` (ручная себестоимость)

Изменения отправляются в БД immédiatement при уходе с поля ( blur ) или по Enter. После успешного сохранения таблица перезагружается (`loadOverview()`), данные актуализируются везде.
