# Что сделано — CRM «Позитив Вектор» (по состоянию на 22.11.2026)

## ✅ Полностью реализовано

### 1. Навигация и разделы
- Порядок вкладок администратора: **Работа → Финансы → Склад → Чат → Документы → Клиенты → Сотрудники → Настройки**
- Порядок вкладок сотрудника: **Работа → Чат → Моя зарплата → Настройки**
- Раздел «Отчёты» убран из главного меню, перенесён внутрь Финансов как вкладка «Отчёты по работе»

### 2. Финансы
- Вкладка «Экономика заказов» объединена со вкладкой «Обзор»
- Кнопка **«Отчёты по работе»** внутри Обзора, открывает `ReportsView`
- **Инлайн-редактирование таблицы «Экономика заказов»:**
  - Цена заказа — `PATCH /api/orders/:id` (`priceKopecks`)
  - Оплачено — `POST /api/finance/payments` (новая оплата)
  - Долг — пересчитывается как `цена − оплачено`
  - Материалы (себестоимость) — `POST /api/finance/orders/:orderId/cost-override`
- Изменения отправляются в БД immédiatement (blur или Enter), таблица перезагружается

### 3. Настройки
- Администратор: вкладки «Мой профиль» + «Компания»
- Сотрудник: вкладки убраны, все настройки в одном списке (профиль, пароль, тема, PWA, push, выход)

### 4. Пуш-уведомления
- Миграция `013_push_subscriptions.sql` — таблица `push_subscriptions`, перенос из `chat_push_subscriptions`, удаление старой таблицы
- `server/services/push.ts` — `sendPushToUser`, `sendPushToRoom`, `notifyPush`
- `server/routes/push.ts` — `GET /key`, `POST /subscription`, `DELETE /subscription` (`/api/push`)
- `server/security.ts` — `notifyUser` вызывает `notifyPush` с `url` (deep link `?order=`, `?task=`, `?chat=`) и `tag`
- `server/routes/chat.ts` — `broadcast()` через `sendPushToRoom`, убраны прямые обращения к `webpush`
- `public/chat-push.js` — `tag`, `data.url`, `notificationclick` с `clients.matchAll`
- `src/lib/push.ts` — `enablePushNotifications()`
- `src/views/SettingsView.tsx` — кнопка «Включить push-уведомления»
- `src/App.tsx` — обработка `?task=` и `?order=` deep links

### 5. Документы
- `server/routes/documents.ts` — `diskStorage`, категории `acts`/`drawings`, `PATCH`/`DELETE`/`GET /download`
