## Бизнес-логика (решения утверждены, код не написан)

1. **Долг клиента**
   - Долг считается **строго по каждому заказу отдельно**: `max(0, цена − оплата заказа)`.
   - Переплата по одному заказу **не перекрывает** долг по другому.
   - Добавляется отдельное поле **«Общий долг по компании»** (сумма долгов по всем активным заказам клиента).

2. **Операция «Возврат клиенту»**
   - Добавляется отдельный тип операции, уменьшающий кассу и оплаченную сумму по заказу.
   - Явно подсвечиваются переплаты (если оплата > цена заказа).
   - Используется при отмене заказа с внесённым авансом.

3. **Материалы: уход от FIFO к средней стоимости**
   - Себестоимость материалов считается от **средневзвешенной по количеству на складе**:
     `Σ(цена × количество) / Σ количество` по всем партиям данного ресурса.
   - Прибыль за месяц привязывается **к датам фактических списаний и оплат**, а не к дате заказа.
   - В общую сводную таблицу «Прибыль за месяц» включаются: выручка, расход на материалы (по средней), ФОТ (зарплата, начисленная за этот месяц), прочие расходы.

4. **ФОТ в экономике заказа**
   - В марже конкретного заказа вычитаются и материалы (средняя стоимость), и зарплата, начисленная за этот заказ.
   - В общей сводной таблице «Прибыль за месяц» ФОТ учитывается как отдельная строка.

5. **Очередь начислений в зарплатах**
   - Смены в цеху, выезды и быстрые задачи — **отдельные независимые** начисления.
   - Смена в цеху **не связана** с визитами и быстрыми задачами.
   - По быстрым задачам допустимо **отсутствие времени** (начисление без таймера).
   - При начислении за смену связанный выезд **не закрывается** автоматически.

6. **Возврат количественного инструмента (без серийного номера)**
   - При возврате через общий склад выбор заказа **не обязателен**: система автоматически закрывает долг по самому раннему открытому заказу сотрудника, на котором числится этот инструмент.
   - Дополнительно рассмотреть автоматические упрощения для монтажников (например, автозакрытие долга, подсказки при возврате).

7. **Увольнение сотрудника**
   - При увольнении/блокировке:
     - автоматически завершить его активный таймер смены (зафиксировать время до момента увольнения);
     - показать админу сводку: невозвращённый инструмент, остаток зарплаты, незакрытые заказы.

## Интерфейс (замечания)

8. **Кнопка «Работа» — выпадающий список открывать вниз**
   - В разделе «Работа» выпадающее меню (Заказы / Быстрые задачи / Смены / Отчёты) должно открываться **вниз под кнопкой** (`top-[calc(100%+8px)]`), а не вверх.
   - Название кнопки: **«Инструменты и работа»** (или сохранить «Работа» — уточнить).

9. **Кнопка «Добавить задачу» с выпадающим списком**
   - В шапке раздела «Работа» кнопка «Добавить задачу» открывается вниз, содержит два варианта:
     - **«Быстрая»** — форма быстрой задачи (доступна всем).
     - **«Заказ»** — форма создания заказа (доступна при правом `orders.create`).

10. **Убрать отдельную кнопку «+ Быстрая задача» под календарём**
    - Дублирующая кнопка «+ Быстрая задача» под календарём убирается; достаточно меню «Добавить задачу».

11. **Финансы → «Отчёты по работе»: сводка по быстрым задачам**
    - Во вкладке «Отчёты по работе» добавить отдельный блок / таблицу со сводкой по быстрым задачам: количество открытых / выполненных, по месяцам, по сотрудникам.

12. **Кнопка «Чаты» вместо переключения комнат**
    - В разделе «Чат» вместо отдельных вкладок комнат одна кнопка **«Чаты»** со стрелкой вниз; выпадающий список содержит **все** комнаты (включая «Общий чат»).
    - По умолчанию открыт «Общий чат».
    - В разделе «Работа» кнопка переименовывается в **«Инструменты и работа»** (см. пункт 8).

13. **Настройки: выпадающие списки по категориям**
    - В «Настройках» администратору: блоки (профиль, оформление, параметры компании, Яндекс Диск, сотрудники) группируются в **аккордеоны** (раскрывающиеся списки), а не в сплошной список.

14. **Форма создания заказа: inline-добавление сущностей**
    - В форме создания заказа (модалка) рядом с полями «Заказчик», «Контакт», «Материалы», «Инструменты» добавить значок **«+»** для мгновенного создания новой сущности прямо из формы.
    - Поле выбора — **автопоиск по части имени** (не просто выпадающий список из готового), с подсветкой подходящих вариантов.
    - Старый способ (создание в отдельных вкладках) сохраняется.

15. **Убрать инфошум из описаний вкладок**
    - Удалить пояснительные подписи под заголовками всех основных разделов («Работа», «Финансы», «Склад», «Настройки», «Чат», «Клиенты», «Документы», «Зарплата», «Сотрудники»).
    - Пример: «Планирование выездов, заказы, быстрые задачи, смены в цеху и отчёты» — убрать.
    - Пример: «Поступления, расходы компании, долги клиентов и экономика заказов» — убрать.
    - Оставить только фактические статусы (время активной смены, статус подключений и т.п.).
