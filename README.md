# Позитив Вектор — CRM/ERP-система

Адаптивная CRM/ERP-система в формате PWA для компании по изготовлению и монтажу рекламных баннеров, декораций, вывесок и металлоконструкций.

Подробный путеводитель для сотрудников и администратора — в [руководстве пользователя](docs/USER_GUIDE.md).

## Ключевые возможности

### Работа, заказы, быстрые задачи и смены
- **Единый раздел «Работа»**: переключение между подразделами **Календарь**, **Заказы**, **Быстрые задачи**, **Смены** и **Отчёты** через выпадающую кнопку с отображением текущего подраздела; кнопка **«Добавить задачу»** объединяет создание быстрой задачи и нового заказа.
- **Создание заказа с inline-подбором**: номер заказа присваивается автоматически; поля **Компания**, **Контакт**, **Теги**, **Материалы** и **Инструменты** оформлены единообразно (переключатель режима «Поиск по имени / Выпадающий список», поле выбора и кнопка `+` для мгновенного создания новой записи), а для монтажников предусмотрен быстрый поиск по имени; выбор компании автоматически подставляет адрес объекта.
- **Единый таймер смен и независимые начисления**: смены в цеху, выезды на заказы и быстрые задачи учитываются отдельно; быстрые задачи могут создаваться без времени/срока.
- **Закрытые заказы**: при завершении или отмене заказа монтажник не может менять состав работ, склад и документы, но при необходимости может дозагружать фото/видео.

### Финансы, себестоимость и долги
- **Строгий учёт долга по заказам**: оплата учитывается строго в рамках выбранного заказа (переплата по одному заказу не гасит долг другого); отдельно рассчитывается суммарный долг и переплата по компании/клиенту.
- **Возвраты клиенту**: отдельный тип операции «Возврат клиенту», который уменьшает кассу и оплаченную сумму по заказу.
- **Экономика и сводка по месяцам**: себестоимость материалов считается по **средневзвешенной стоимости**; выручка, списание материалов, выплаченный и начисленный ФОТ и операционные расходы сводятся по датам фактических оплат и списаний в общей помесячной таблице.

### Склад и инструменты
- **Материалы**: оприходование, резервирование под заказы без преждевременного списания, выдача, расход по заказу и возврат с расчётом средневзвешенной стоимости.
- **Инструменты (количественные и поштучные)**: при возврате количественного инструмента долг сотрудника автоматически закрывается по самому раннему открытому заказу.

### Клиенты, документы и сотрудники
- **Клиенты**: фильтр **«С долгом»** для администратора, разворачиваемый список всех заказов в карточках компаний и контактов, быстрый переход к звонку, карте и созданию заказа.
- **Документы**: разделение на акты и чертежи, привязка к заказам, встроенный предпросмотр изображений/PDF/TXT.
- **Сотрудники и увольнение**: при увольнении открытая рабочая смена сотрудника автоматически закрывается с фиксацией времени, активные сессии завершаются, а администратору выводится сводка (инструмент на руках, расчёты по зарплате, активные заказы). Уволенный пользователь при входе видит только статус увольнения и актуальный остаток к выплате. При восстановлении прежний пароль действует с обязательным запросом на смену.

### Чаты и уведомления
- **Компактный переключатель «Чаты»**: по умолчанию открывается **Общий чат**, дополнительные комнаты (до пяти) выбираются из выпадающего списка. Поддерживаются текст, файлы, ответы на сообщения и голосовые записи (требуется HTTPS и разрешение микрофона).
- **Права и история**: автор может редактировать сообщение 5 минут, администратор — свои сообщения 24 часа; доступ к прошлой истории общего чата для нового сотрудника задаётся при создании учётной записи.
- **Web Push**: настраивается через `WEB_PUSH_PUBLIC_KEY`, `WEB_PUSH_PRIVATE_KEY` и `WEB_PUSH_SUBJECT` (`npx web-push generate-vapid-keys`).

### Эргономика интерфейса
- Однострочная адаптивная шапка разделов (вкладки и кнопки не наезжают и не разбиваются на лишние ряды на широком экране).
- Настройки сгруппированы в сворачиваемые категории-аккордеоны.
- Быстрый сброс поиска (`×`) во всех разделах и закрытие модальных окон, предпросмотра файлов и выпадающих меню клавишей `Esc`.

## Стек технологий

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, `vite-plugin-pwa`, `lucide-react`
- **Backend**: Node.js (`>= 22.13` со встроенным `node:sqlite`), Express, TypeScript (`tsx`)
- **База данных**: SQLite (`node:sqlite`, режим `WAL`, `PRAGMA foreign_keys = ON`, миграции `server/migrations/001..023`, `BEGIN IMMEDIATE` транзакции)
- **Авторизация и безопасность**: `crypto.scryptSync`, HTTP-only cookie (`pv_session`), CSRF-токены (`X-CSRF-Token`), ограничение попыток входа (`login_attempts`), серверный RBAC
- **Файлы, бэкапы и экспорт**: `multer` (хранение в `UPLOAD_DIR` с проверкой прав доступа), экспорт в `.xlsx` (`xlsx`), локальные бэкапы (ежедневно в 04:00 МСК, хранятся 3 последних дня)

## Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Переменные окружения
Настройте переменные окружения (можно ориентироваться на `.env.example`):
- `PORT=3000`
- `HOST=0.0.0.0`
- `DB_PATH=./data/pozitiv_vektor.sqlite`
- `UPLOAD_DIR=./data/uploads`
- `SESSION_SECRET=<случайная-строка-не-менее-32-символов>` (обязательно в `production`)
- `COOKIE_SECURE=false` (`true` при работе по HTTPS)
- `SESSION_TTL_HOURS=168`

### 3. Миграция базы данных
```bash
npm run migrate
```

### 4. Первый запуск и учётные записи
- **Веб-интерфейс**: откройте приложение в браузере — при пустой таблице `users` откроется экран создания первого администратора.
- **CLI (создание администратора)**: `npm run create-admin`
- **Демо-данные**: `npm run seed:demo`

### 5. Разработка, тестирование и сборка
```bash
# Разработка (Express + Vite на одном порту 3000)
npm run dev

# Проверка типов и автотесты
npm run lint
npm test

# Сборка фронтенда и запуск production-сервера
npm run build
NODE_ENV=production npm start
```
